# Aoi の使い方

Aoi はブルーアーカイブの画面を横から見て、アイテムや装備の所持数、生徒の育成状況、ショップの残り購入回数を数えます。集めた数から、育てたい生徒に足りない素材と、それを選択ボックスやショップでどう補うかも計算します。ゲームは操作せず、読んだ内容はこのパソコンの中だけに保存します（インターネットにつなぐのは、アップデートの確認とダウンロードのときだけです）。
