# お仕事タブの見方

どこを回るかと、月末に何を買っておくかの目安が出ます。

<div class="movie" data-spec="work"></div>

1. アイテム・装備・ショップを[読ませておく](reading.md)（読ませていない分は 0 として数えます）
2. 「お仕事」タブで、見たい項目の見出しを押して開く
3. 赤やオレンジの品から先に集める

## ゲームの画面についてくる

<div class="movie" data-spec="follow"></div>

<details markdown="1">
<summary>ついてくる画面と、止め方</summary>

お仕事タブを開いたままゲームで次の画面を開くと、その項目が開いて一番上に来ます。ほかの項目は閉じます。

| ゲームの画面                                               | 開く項目               |
| ---------------------------------------------------------- | ---------------------- |
| 学園交流会・指名手配・特別依頼                             | 同じ名前の項目         |
| ショップの通常アイテム                                     | ショップ: 通常アイテム |
| ショップの総力戦・大決戦・合同火力演習・指名手配・熟達証書 | 月末のそのショップ     |
| 任務（「キャンペーン中」の表示があるとき）                 | 任務 Normal            |

- 任務の画面でついてくるのは、任務 Normal の報酬が増えるキャンペーン中だけです。
- 開いた項目を自分で閉じると、その画面にいる間は閉じたままです。
- 学園交流会・指名手配・特別依頼・通常アイテムのショップ・任務の画面にいる間、右上の表示はその画面名（「指名手配」など）になります。数を読む画面ではないので「集計中」にはなりません。
- 月末のショップは数も読むので、右上は「ショップを集計中」になります。
- 止めるには、右上の ≡ で設定を開き、「お仕事の自動開閉」で「しない」を選びます。自動では開閉もスクロールもしなくなります。

</details>

## 日課

| 項目                   | 出る数                                             | 色                                 |
| ---------------------- | -------------------------------------------------- | ---------------------------------- |
| ショップ: 通常アイテム | クレジットと強化珠で、Lv1 の生徒を何人育てられるか | 少ない方が赤                       |
| 指名手配               | 落ちる品の手持ち                                   | 赤・青・緑（1 人分・2 人分が境目） |
| 学園交流会             | 強化素材で、固有武器を何本育てられるか             | 先に足りなくなる学園が赤           |

指名手配で迷ったら、赤や青の品が落ちる場所から回ります。

<details markdown="1">
<summary>日課の見方と計算式</summary>

- ショップ: 通常アイテム・学園交流会と、2倍キャンペーンの特別依頼は、装備タブの「強化素材」と同じ形です。名前の下の行に手持ち（初級〜最上級の所持数か、クレジットのアイコンと所持数）、右端に「N.N人分」とその計算式が並びます。
- 「4.5人分」のような数は、小数第 2 位以下を切り捨てます。足りていない数を、四捨五入で足りているように見せないためです。

**ショップ: 通常アイテム**（強化珠は、実質ここでそろえることになります）

- クレジット: [特別依頼](#特別依頼の計算式)と同じ数え方です。
- 強化珠: 装備 3 か所を T1 から T10 まで強化するのに要る経験値で割ります。
  - 装備は Tier ごとに Lv1 から最大レベルまで上げてから、次の Tier にします。これを 10 回くり返します。
  - 最大レベルを超えた分の経験値は消えます。そこで、Tier ごとに一番小さい強化珠（初級、経験値 90）の単位で切り上げます。
- 2 つのうち多い方を緑で出します。

**指名手配**

| 色  | 意味                  |
| --- | --------------------- |
| 赤  | 生徒 1 人分に足りない |
| 青  | 生徒 2 人分に足りない |
| 緑  | 生徒 2 人分以上       |

- 場所ごとに、落ちる技術ノート・BD・オーパーツの所持数を、初級〜最上級の順に並べます。
- 生徒 1 人分は、スキルと能力解放を最大まで上げる量の目安です。

**学園交流会**

- 場所ごとに、落ちる固有武器の強化素材の所持数を、初級〜最上級の順に並べます。
- 行の右端に「N.N人分」、その下に計算式（1.5 倍した手持ちの経験値と「/ 1 本分の経験値」）を出します。
- 固有武器 1 本分は、Lv1 から ★4 の上限の Lv60 までの経験値（49,605）です。
- 素材は、合う武器種の固有武器に使うと経験値が 1.5 倍になります（ゲームのデータ CharacterWeaponExpBonus より）。そこで、手持ちの経験値を 1.5 倍して数えます。

  | 学園・素材             | 合う武器種      | 使う生徒の割合 |
  | ---------------------- | --------------- | -------------: |
  | トリニティのスプリング | SG・SMG・HG・FT |            46% |
  | ゲヘナのハンマー       | AR・GL・RL      |            26% |
  | ミレニアムの銃身       | MG・SR・RG・MT  |            28% |

- 割合は 2026-10 時点の実装生徒のものです（約 2:1:1）。同梱の生徒データから数えるので、生徒が増えると変わります。
- 「N.N人分」をこの割合で割ったとき、一番少ない学園を赤で示します。
- 学園の行にマウスを乗せると、割合と、割った値（「6.6人分 ÷ 46% = 14.5」）が出ます。

</details>

## 2倍キャンペーン

| 項目        | 出るもの                                                    | 色・操作                                                    |
| ----------- | ----------------------------------------------------------- | ----------------------------------------------------------- |
| 任務 Normal | 部位ごとに、手持ちの設計図で T1 から T10 まで何個分作れるか | 1 個分に足りないと赤、[黄金比](#黄金比)に足りないとオレンジ |
| 任務 Hard   | Hard で神名文字が出る生徒のカード                           | 押すと予約。1 日に使う AP が出る                            |
| 特別依頼    | レポートとクレジットで、Lv1 の生徒を何人育てられるか        | 少ない方がオレンジ                                          |

- 任務 Normal の下に、黄金比までどのステージを何回回るかが出ます。
- キャンペーンでないときは、2 倍の回数が目安です。

<details markdown="1">
<summary>任務 Normal の数え方と、周回の選び方</summary>

- 部位は帽子・グローブ・シューズ・バッグ・バッジ・ヘアピン・お守り・腕時計・ネックレスです。
- 「T10設計図」と「万能設計図」の列に分かれます。
- T9 以下の設計図は、万能設計図に換算して数えます（T2 は 2 枚、…、T9 は 30 枚）。
- 部位名にマウスを重ねると、その部位の黄金比と計算が出ます。

**黄金比までの周回（2倍キャンペーン中）**

両方の列を黄金比までそろえる回数を、AP が一番少なくなるように出します。

- ステージごとに、設計図が落ちる部位を、ドロップ率が高い順に並べます（1 つだけ 3 割ほど多く落ちます）。最後の行が合計です。
- 先に T10 設計図を黄金比までそろえます。
  - 万能設計図は、50 枚で T10 設計図 1 枚にしかなりません。
  - そこで T10 設計図は周回で集め、万能設計図は T9 以下に使う分として取っておきます。
- 同じ AP で済む周回が複数あるときは、一緒に落ちる T10 設計図の価値が高い方を選びます。
  - 価値は、ドロップ率をその部位の黄金比の達成比率で割った数です（黄金比の 2 倍あれば半分の価値）。
  - 例: バッグとバッジが黄金比を大きく超えていれば、ヘアピンは 28-4（バッグ・バッジも落ちる）ではなく 29-2（靴・腕時計も落ちる）で集めます。
- T10 設計図がそろったあとも T9 以下（万能設計図の列）が足りなければ、その分の周回を足します。

**その後に黄金比を整える周回**

- 上の周回を終えたあとに回すとよいステージを、3 つ出します。
- T10 設計図が落ちるステージを、同じ価値の高い順に並べます。
- 任務のドロップは、部位の組み合わせが偏っています。この 3 つは、回るたびに黄金比の形へ近づけるための目安です。

</details>

<details markdown="1" id="黄金比">
<summary>黄金比</summary>

装備設計図を、部位ごとに何人分（T1 から T10 まで仕上げる分）蓄えておくかの目安です。

- ゲームの中の言葉ではありません。YouTube の「[オニア先生のブルアカ攻略](https://www.youtube.com/@ONIABlue)」で紹介された「オニア先生の黄金比」の考え方を元にしました。
- 新しい生徒は毎月のように来て、急に育てたくなります。一方、任務の 2 倍キャンペーンは月に 1 週間ほどです。
- そこで、よく使われる部位の設計図を、あらかじめ多めに蓄えておきます。

**数え方**

1. 全実装生徒の装備欄（1 人 3 つ）のうち、各部位が占める割合を出す
2. オニア先生の黄金比と同じ、合計 24 人分に換算する
3. 小数点以下が 0.24 以下なら切り捨て、0.25 以上なら切り上げる

2026-10-17 時点（実装済みの 278 人、装備欄 834）では次のとおりです（小数点以下は表示の桁で切り捨て）。

| 部位       | 生徒数 |  割合 | 24 人分に換算 | 黄金比 |
| ---------- | -----: | ----: | ------------: | -----: |
| 帽子       |    103 | 12.3% |          2.96 |      3 |
| グローブ   |     74 |  8.8% |          2.12 |      2 |
| シューズ   |    101 | 12.1% |          2.90 |      3 |
| バッグ     |     58 |  6.9% |          1.66 |      2 |
| バッジ     |     44 |  5.2% |          1.26 |      2 |
| ヘアピン   |    176 | 21.1% |          5.06 |      5 |
| お守り     |     38 |  4.5% |          1.09 |      1 |
| 腕時計     |    163 | 19.5% |          4.69 |      5 |
| ネックレス |     77 |  9.2% |          2.21 |      2 |

**0.25 で切り上げる理由**

- 四捨五入で切り捨てると、足りなかったときに困ります。
- 設計図の在庫は、整数の人数分でないと役に立ちません。黄金比が 2.5 人分でも、T10 設計図が 150 枚（2.5 人分）あればよいわけではありません。

**知っておくこと**

- 新しい生徒が実装されて Aoi のデータが更新されると、黄金比も数え直します。
- Aoi の作者は「全生徒が要求する装備の種類から見て、1 か月にこの人数分の T10 装備を作れる設計図を確保しておけば安全圏」と受け止めて、この数を目安にしています。個人の受け止め方なので、育成の方針に合わせて読み替えてください。

</details>

<details markdown="1">
<summary>任務 Hard のカード</summary>

Hard で神名文字が出る生徒を、月末のショップと同じカードで並べます。

| カードの場所   | 出るもの                                                                             |
| -------------- | ------------------------------------------------------------------------------------ |
| アイコンの右下 | その生徒の神名文字が出る Hard ステージの数（「3個所」）                              |
| 下             | 今の星（ゲームと同じ★の絵。固有武器の星は青）と、手持ちの神名文字の数（「148文字」） |
| マウスを乗せる | ステージ（「1-1、4-3、12-2」）と、それを 1 日 3 回ずつ回す AP                        |

- 生徒タブやアイテム一覧で読んでいないものは「?」です。
- 初期★3 の生徒が先です。★2 と★1 の生徒は、その後に名前の順で並びます。
- 固有4 になった生徒は、灰色で最後です。文字数は出て、予約もできます（固有5 に備えて集める場合）。
- カードを押すと予約中になります。「任務 Hard」の見出しの右に、予約した生徒の Hard を 1 日回す AP が赤字で出ます（例: 「-360」）。
- AP の所持は読まないので、出るのは使う分だけです。
- 予約は保存されます。書き出す YAML の `reserved` に `shop: 任務 Hard` として載ります。

</details>

<details markdown="1" id="特別依頼の計算式">
<summary>特別依頼の計算式</summary>

ゲームと同じく、拠点防衛（レポート）を上に並べます。

- レポート: Lv1 から Lv90 まで上げるのに要る経験値で割ります。
- クレジット: Lv90、スキル 5/10/10/10、装備 T10、固有武器の ★4・Lv60 まで育てるのに要る量で割ります。
- 2 つのうち多い方を緑で出します。

</details>

## 月末

1. ゲームでショップを開いて、下まで送る
2. 今月のうちに買っておく品のカードを押して、予約する
3. 見出しの右で、予約した分を引いたコインの残りを見る

<details markdown="1">
<summary>対象のショップと、並べる品</summary>

総力戦・大決戦・合同火力演習・指名手配・熟達証書のショップは、毎月品ぞろえが入れ替わります。足りなくなりそうな品を、今月のうちに買っておくための項目です。

- まだ読んでいないショップには「まだ読んでいません」と出ます。
- ゲームのカードと同じく、品と払うコインの組ごとに 1 枚ずつ並べます。

| ショップ       | 並べる品                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| 総力戦・大決戦 | 生徒の神名文字、秘伝ノート、3 大校（ゲヘナ・トリニティ・ミレニアム）の上級・最上級の技術ノートと BD        |
| 合同火力演習   | 生徒の神名文字、秘伝ノート、テイラーストーン、オーパーツ                                                   |
| 指名手配       | 生徒の神名文字、最上級のオーパーツ                                                                         |
| 熟達証書       | フェス限定生徒と限定生徒の神名文字、神名のカケラ。その後ろに最上級レポート・チタン撃針・クレジットポイント |

熟達証書の最上級レポート・チタン撃針・クレジットポイントは、交換する先生のための候補として後ろに並べます。

</details>

<details markdown="1">
<summary>予約とコインの残り</summary>

| こと                           | 出方                                                     |
| ------------------------------ | -------------------------------------------------------- |
| カードを押す                   | 青い枠で囲まれ、右上に「予約中」。もう一度押すと外れる   |
| コインの残り（見出しの右）     | 所持数 −（予約したカードの価格 × 残り回数）              |
| 予約があるとき                 | 残りを青で出す（ゲームの所持数と区別するため）           |
| 足りないとき                   | マイナスの数を赤で出す                                   |
| 売り切れたカード               | 灰色                                                     |
| 固有武器が ★4 の生徒の神名文字 | 買えないので灰色。固有武器の青い★ 4 個を出し、最後に回す |

- 残りにマウスを乗せると、所持数と予約の分が出ます。
- 予約は保存され、Aoi を開き直しても残ります。保存する YAML にも `reserved` として載ります。
- 予約は、売り切れても月が替わっても外れません。毎月買うものは大きく変わらないからです。
- カードにマウスを乗せると、品名と所持数が出ます。神名文字には、その生徒の星（★1〜★4、固有1〜固有4）も出ます。
- 星は、熟達証書で生徒が固有2 に届いているか、アタッカーを固有3・4 まで上げるかを決めるときの目安です。

</details>
