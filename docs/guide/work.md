# お仕事タブの見方

お仕事タブは、毎日の任務や指名手配などで手に入るものや、月末に買っておくショップの品を、手持ちと比べて
見るためのタブです。アイテム一覧・装備一覧・クレジット・ショップの読み取り結果を使います
（[ゲームの画面を読ませる](reading.md)）。読ませていない分は 0 として数えます。

中身は、遊ぶ時期ごとに「日課」「2倍キャンペーン」「月末」に分かれています。各項目は、見出しを押すと開きます。

## 日課

### ショップ: 通常アイテム

通常アイテムのショップでは、毎日クレジットで強化珠を少しずつ買えます。装備を強化する強化珠は、
実質ここでそろえることになります。そこで、手持ちのクレジットと強化珠で、Lv1 の生徒を何人育てられるかを
並べます。

- クレジット: [特別依頼](#特別依頼)と同じ数え方です。
- 強化珠: 装備 3 か所を T1 から T10 まで強化するのに要る経験値で割ります。装備は Tier ごとに
  Lv1 から最大レベルまで上げてから次の Tier にするので、Lv1 から最大レベルまでを 10 回くり返します。
  最大レベルを超えた分の経験値は消えるので、Tier ごとに一番小さい強化珠（初級、経験値 90）の
  単位で切り上げて数えます。
- 2 つのうち多い方が緑、少ない方が赤です。赤の方が、先に足りなくなります。

### 指名手配・学園交流会

場所ごとに、落ちるもの（技術ノート・BD・オーパーツ、学園交流会は固有武器の強化素材）の
所持数を、初級〜最上級の順に並べます。

指名手配では、生徒 1 人分（スキルと能力解放を最大まで上げる量の目安）と比べて色が付きます。

- 赤: 1 人分に足りない
- 青: 2 人分に足りない
- 緑: 2 人分以上ある

どの指名手配を回るか迷ったときは、赤や青の品が落ちる場所を先に回ると、足りないものから集まります。

## 2倍キャンペーン

### 任務 Normal

装備の部位（帽子・手袋・靴・バッグ・バッジ・ヘアピン・お守り・腕時計・ネックレス）ごとに、
手持ちの設計図で T1 から T10 まで何個分作れるかを出します。

- 「T10設計図」と「万能設計図」の列に分かれます。T9 以下の設計図は、万能設計図に換算して
  数えます（T2 は 2 枚、…、T9 は 30 枚）。
- 1 個分に足りないときは赤、[オニア先生の黄金比](#オニア先生の黄金比)に足りないときはオレンジです。
  黄金比は 帽子 3・手袋 2・靴 4・バッグ 2・バッジ 2・ヘアピン 4・お守り 1・腕時計 4・ネックレス 2 人分です。
- 下の「黄金比までの周回（2倍キャンペーン中）」に、T10設計図と万能設計図の両方の列を
  黄金比までそろえるのに、どのステージを何回回ればよいかを、AP が一番少なくなるように出します。
  ステージごとに、設計図が落ちる部位を、ドロップ率が高いもの（1 つだけ 3 割ほど多く落ちます）から順に並べます。
  最後の行が合計です。この回数を目安に、2 倍キャンペーンの間に周回します。
  キャンペーンでないときは、この 2 倍の回数が目安です。
  - 先に T10 設計図を黄金比までそろえます。万能設計図は 50 枚で T10 設計図 1 枚にしかならないので、
    T10 設計図は周回で集め、万能設計図は T9 以下に使う分として取っておきます。
  - 同じ AP で済む周回が複数あるときは、一緒に落ちる T10 設計図の価値が高い方を選びます。価値は、
    ドロップ率をその部位の黄金比の達成比率で割った数です（黄金比の 2 倍あれば半分の価値）。
    たとえばバッグとバッジが黄金比を大きく超えていれば、ヘアピンは 28-4（バッグ・バッジも
    落ちる）ではなく 29-2（靴・腕時計も落ちる）で集めます。
  - T10 設計図がそろったあとも T9 以下（万能設計図の列）が足りなければ、その分の周回を足します。
- 「その後に黄金比を整える周回」に、上の周回を終えたあとに回すとよいステージを 3 つ出します。
  T10 設計図が落ちるステージを、同じ価値の高い順に並べます。任務のドロップは部位の組み合わせが
  偏っているので、回るたびに黄金比の形へ近づけていくための目安です。

#### オニア先生の黄金比

ゲームの中の言葉ではありません。YouTube の
「[オニア先生のブルアカ攻略](https://www.youtube.com/@ONIABlue)」で紹介された、装備設計図の在庫の目安です。
全生徒がどの部位の装備を要求するかの偏りから、部位ごとに「何人分の装備を T1 から T10 まで
仕上げられる設計図を持っておくか」を決めています。

ブルーアーカイブには毎月のように新しい生徒が来て、急に育てたくなることがあります。
一方で、任務の 2 倍キャンペーンは月に 1 週間ほどしかありません。そこで、よく使われる部位の
設計図をあらかじめ多めに蓄えておく、という考え方です。

Aoi の作者は、「全生徒が要求する装備の種類から見て、1 か月にこの人数分の T10 装備を作れる
設計図を確保しておけば安全圏」と受け止めて、この数を目安にしています。個人の受け止め方なので、
育成の方針に合わせて読み替えてください。

詳しい出典と、黄金比を満たすための周回の計算は schale-calc にまとめています。

- [オニア先生の黄金比](https://github.com/miyabisun/schale-calc/blob/main/equipment-blueprint/docs/onia-golden-ratio.md)（出典の動画と部位ごとの人数）
- [オニア先生の黄金比を満たす最小 AP プラン](https://github.com/miyabisun/schale-calc/blob/main/equipment-blueprint/docs/onia-golden-plan.md)

### 特別依頼

手持ちのレポートとクレジットで、Lv1 の生徒を何人育てられるかを出します。ゲームと同じく、
拠点防衛（レポート）を上に並べます。

- レポート: Lv1 から Lv90 まで上げるのに要る経験値で割ります。
- クレジット: Lv90、スキル 5/10/10/10、装備 T10、固有武器の ★4・Lv60 まで育てるのに要る量で割ります。
- 2 つのうち多い方が緑、少ない方がオレンジです。オレンジの方が、先に足りなくなります。

## 月末

総力戦・大決戦・合同火力演習・指名手配・熟達証書のショップは、毎月品ぞろえが入れ替わります。
足りなくなりそうな品を今月のうちに買っておき、来月の枠も使えるように、買う品を決めておくための場所です。
ショップのタブと同じく、ゲームでショップを開いて下まで送ると読み取ります。まだ読んでいないショップには
「まだ読んでいません」と出ます。

各ショップには、ゲームのカードと同じく、品と払うコインの組ごとに 1 枚ずつ並べます。並べる品は次のとおりです。

| ショップ       | 並べる品                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------- |
| 総力戦・大決戦 | 秘伝ノート、生徒の神名文字、3 大校（ゲヘナ・トリニティ・ミレニアム）の上級・最上級の技術ノートと BD |
| 合同火力演習   | 秘伝ノート、生徒の神名文字、テイラーストーン、オーパーツ                                            |
| 指名手配       | 生徒の神名文字、最上級のオーパーツ                                                                  |
| 熟達証書       | 神名のカケラ、フェス限定生徒と限定生徒の神名文字                                                    |

- カードを押すと、青い枠で囲まれて「予約中」になります。もう一度押すと外れます。予約は保存され、
  Aoi を開き直しても残ります。書き出す YAML にも `reserved` として載ります。
- 見出しの右に、コインの所持数を出します。予約したカードを残り回数ぶん全部買うのにコインが足りないときは、
  足りない枚数を赤で添えます。
- 売り切れたカードは灰色になります。予約は、売り切れても月が替わっても外れません。毎月買うものは
  大きく変わらないからです。
- 固有武器が ★4 になった生徒の神名文字は買えないので、灰色にして「固有4」と書き、最後に回します。
