# ゲームの画面を読ませる

ゲームで一覧を開いてゆっくり送ると、読めたものから Aoi のタブに並びます。

<div class="movie" data-spec="reading"></div>

- 先に Aoi とブルーアーカイブを起動しておきます（[Aoi の入手](https://github.com/miyabisun/bluearchive-aoi#ダウンロードと起動)）。
- 読めているかは、Aoi の右上の表示で分かります（「アイテムを集計中」など。[表示の意味](trouble.md#右上の表示の意味)）。
- スマホで遊ぶときは、先に画面を Aoi へ送ります（[Android](android.md)・[iPhone](stream.md)）。

## アイテムと装備

1. ホームの右上の ≡ から「アイテム」か「装備」を開く
2. 右側の並び順を「デフォルト」の上向き（≡↑）にする
3. 1 回スクロールしたら一瞬止める、をくり返して下まで送る

<details markdown="1">
<summary>読むときに覚えておくこと</summary>

| こんなとき                                               | Aoi の動き                                    |
| -------------------------------------------------------- | --------------------------------------------- |
| 並び順が「デフォルト」の上向き以外                       | 数えない。右上は「対象外の画面」              |
| 速く流した                                               | 読み飛ばす。同じ数を 3 回続けて読めたら決める |
| ほかのウィンドウが重なった（PC 版）                      | 読める                                        |
| ゲームを最小化した（PC 版）                              | 読めない                                      |
| 1 万個以上ある                                           | ゲームと同じ「51K」（千単位）                 |
| 使い切って、ゲームの一覧から消えた                       | 前後のアイテムが並んで見えたときに 0 個にする |
| 一度も読んでいない                                       | 出ない（0 個にもならない）                    |
| イベントのアイテム（ポイントやバレンタインのチョコなど） | 数えない                                      |

- 0 個になったアイテムは Aoi から消えません。`aoi.yaml` にも `count: 0` で残ります。
- 一覧の最初の方のアイテムは、一番上までスクロールしたときに 0 個になります。

</details>

<details markdown="1">
<summary>アイテムタブの見方</summary>

| 分類       | 並ぶもの                                                              |
| ---------- | --------------------------------------------------------------------- |
| 全体       | すべてのアイテム。「名前で検索」はここだけ                            |
| スキル素材 | 選択ボックス、秘伝ノートとその断片、学園ごとの戦術教育BD と技術ノート |
| オーパーツ | オーパーツの選択ボックス、その下に種類ごとに 1 行                     |
| 通貨等     | クレジットとレポート（手持ちと、生徒何人分か）、各種コインの所持数    |

- アイコンにマウスを乗せると、名前が出ます。神名文字では、その生徒の星（★3、固有2 など）も出ます。
- 「全体」の背景はレアリティの色です。初級は灰、中級は青、上級は黄、最上級は紫、神名文字はピンクです。
- 「名前で検索」に入力すると、そのアイテムだけに絞れます。ひらがなで入力しても、カタカナの名前が見つかります。
- 「スキル素材」の並び
  - 選択ボックスは、選べる学園の組ごとに 2 行です。左の「全学園」「6校」にマウスを乗せると学園名が出ます。
  - 学園ごとに、上の行が戦術教育BD、下の行が技術ノートです。校章が付き、トリニティ・ゲヘナ・ミレニアムが先頭です。
- 「スキル素材」と「オーパーツ」の色は、お仕事タブの指名手配と同じです。

  | 色  | 意味                  |
  | --- | --------------------- |
  | 赤  | 生徒 1 人分に足りない |
  | 青  | 生徒 2 人分に足りない |
  | 緑  | 生徒 2 人分以上       |

- 「通貨等」のクレジットとレポートは、お仕事タブの特別依頼と同じ形です。
- 熟達証書の数は、熟達証書のショップを読んだときのものです。

</details>

<details markdown="1">
<summary>装備タブの見方</summary>

| 分類     | 並ぶもの                                                              |
| -------- | --------------------------------------------------------------------- |
| 全体     | 部位ごとに、T1〜T10 の装備、T2〜T10 の設計図、万能設計図の順          |
| 設計図   | 部位ごとに 1 行。T1 の装備、T2〜T10 の設計図、万能設計図の個数        |
| 強化素材 | 強化珠・スプリング・ハンマー・銃身・撃針が 1 行ずつ（初級から最上級） |

- アイコンにマウスを乗せると、名前が出ます。
- 「全体」では、左下に「T6」のようなティアが付きます。
- 「設計図」の最下部に、T2〜T10 の装備設計図選択ボックスの個数が並びます。
- 「強化素材」の右端に、生徒何人分かと計算式が出ます（お仕事タブと同じ数です）。

  | 素材                             | 1 人分                                        |
  | -------------------------------- | --------------------------------------------- |
  | 強化珠                           | 生徒 1 人の装備 3 部位を T1〜T10 まで上げる分 |
  | スプリング・ハンマー・銃身・撃針 | 固有武器 1 本を上限まで上げる分               |
  - 計算式は 2 行で、手持ちの経験値と「/ 1 人分の経験値」です。
  - スプリング・ハンマー・銃身・撃針の手持ちの経験値は、1.5 倍した値です。
  - スプリング・ハンマー・銃身は合う武器種の固有武器が、撃針はすべての固有武器が、1.5 倍の経験値で受け取るからです（ゲームのデータ CharacterWeaponExpBonus より）。

</details>

## 生徒

<div class="movie" data-spec="students"></div>

1. ホームの下の「生徒」から誰か 1 人を選び、右側の「基本情報」タブを開く
2. 画面の左右の端の「＜」「＞」で、1 人ずつ 1 秒ほど止めながら送る

<details markdown="1">
<summary>生徒タブの見方</summary>

| 列       | 意味                                                            |
| -------- | --------------------------------------------------------------- |
| 育成     | 印を付けると、育成タブで必要な素材を計算（[育成タブ](plan.md)） |
| Lv       | レベル                                                          |
| 星       | ゲームと同じ★の絵                                               |
| スキル   | EX、続けてほかの 3 つのレベル。最大（Lv10）は M。例: `5M7M`     |
| 装備     | 3 つの装備のティア。例: `T10/9/8`                               |
| 愛用品   | 愛用品のティア。ない生徒は —                                    |
| 能力解放 | 能力解放の 3 つのレベル                                         |
| 絆       | 絆ランク                                                        |

- 星: ★1〜★4 は黄色い★、その上は固有武器の青い★です（★5 は青い★ 1 個）。
- 星にマウスを乗せると、固有武器のレベルと、その生徒の神名文字の所持数が出ます（アイテム一覧で読んでいなければ「?」）。
- 装備のレベルは読みません。そのティアの最大とみなします。
- 読み取れなかった項目は「?」です。もう一度その生徒を表示すると埋まります。
- 「レベルアップ」「神秘解放」タブでも、名前とレベルは読みます。レベルを上げた生徒は、「基本情報」に戻らなくても新しいレベルになります。
- タブの名前の横の数（「生徒 42」）は、読めた人数です。ゲームの所持人数と比べると、読み漏れが分かります。名前を読めなかった生徒は数えません。
- 並びは、レベルの高い順です。同じなら星の高い順、その次に絆の高い順です。列の見出しを押すと、その列の高い順に並べ替えます。

</details>

## ショップ

<div class="movie" data-spec="shops"></div>

1. ホームの下の「ショップ」で、読む店を選ぶ
2. 右側の品物を、一番下までゆっくりスクロールする

<details markdown="1">
<summary>読む店と、ショップタブの見方</summary>

| 店                                                             | 読むか   |
| -------------------------------------------------------------- | -------- |
| 総力戦・大決戦・カケラ(文字)・合同火力演習・指名手配・熟達証書 | 読む     |
| 通常・青輝石・カケラ(その他)・戦術対抗戦                       | 読まない |

- 買い切った品は、ゲームでは一番下にあります。
- 店の名前を押すと開きます。名前の右に、その店のコインの所持数が出ます。
- 名前の横の時刻は、その店のコインの所持数か品物を、最後に読み取って変わった時刻です。
- 品物は、買う価値の高い順に並びます（生徒の神名文字、神名のカケラ、秘伝ノート、テイラーストーン、BD、技術ノート、オーパーツ…）。
- 全部買い切った品は、一番下で灰色になります。
- 品物の下に、コインのアイコンと「残り回数@値段」（例: `40回@10`）か「売切れ」が出ます。
- 総力戦と大決戦は、上の行が通常コイン、下の行がレアコインです。
- カケラ(文字) 以外の店は、毎月 1 日の午前 4 時に残り回数が戻ります。それより前に読んだ店には「前の月の値」と出るので、もう一度読ませてください。

</details>

## クレジット

ゲームの画面の上にあるクレジットは、表示されている画面ならどこでも読みます。

<details markdown="1">
<summary>クレジットの使い道</summary>

育成タブの計算と、お仕事タブの特別依頼に使います。

</details>
