# ゲームの画面を読ませる

ゲームで一覧を開いて、ゆっくりスクロールするだけです。読めたものから Aoi のタブに並びます。

<div class="movie" data-spec="reading"></div>

先に Aoi とブルーアーカイブを起動しておきます（Aoi の入手は [ダウンロードと起動](https://github.com/miyabisun/bluearchive-aoi#ダウンロードと起動)）。読めているかは、Aoi の右上の表示で分かります（「アイテムを集計中」など。[表示の意味](trouble.md#右上の表示の意味)）。スマホで遊ぶときは、先にスマホの画面を Aoi に送っておきます（[Android](android.md)、[iPhone](stream.md)）。

## アイテムと装備

1. ホームの右上の ≡ から「アイテム」（装備なら「装備」）を開く
2. 右側の並び順を「デフォルト」の上向き（≡↑）にする
3. 1 回スクロールしたら一瞬止める、をくり返して下まで送る

<details markdown="1">
<summary>読むときに覚えておくこと</summary>

- 並び順が「デフォルト」の上向き以外のときは数えず、右上に「対象外の画面」と出ます。
- 同じ数を 3 回続けて読めたときに数を決めます。速く流しすぎると読み飛ばします。
- PC 版では、ほかのウィンドウがゲームに重なっていても読めます。ゲームを最小化すると読めません。
- 個数が 1 万以上のものは、ゲームと同じく「51K」のように千単位で出ます。
- ゲームでアイテムを使い切ると、ゲームの一覧から消えます。Aoi からは、そのアイテムの前後が並んで見えたときに消えます。一覧の最初の方のアイテムなら、一番上までスクロールしたときです。
- イベントのアイテム（イベントのポイントやバレンタインのチョコなど）は数えません。

</details>

<details markdown="1">
<summary>アイテム・装備タブの見方</summary>

- アイコンにマウスを乗せると、名前が出ます。生徒の神名文字では、その生徒の星（★3、固有2 など）も出ます。
- 「全体」では、アイテムの背景がレアリティの色（初級は灰、中級は青、上級は黄、最上級は紫）になります。生徒の神名文字はピンクです。
- 「名前で検索」に入力すると、そのアイテムだけに絞れます。ひらがなで入力しても、カタカナの名前が見つかります。検索は「全体」だけにあります。
- 「スキル素材」には、秘伝ノートと秘伝ノートの断片、学園ごとの戦術教育BD（上の行）と技術ノート（下の行）が校章と一緒に並びます。トリニティ・ゲヘナ・ミレニアムが先頭です。「オーパーツ」には、オーパーツが種類ごとに 1 行で並びます。どちらも、お仕事タブの指名手配と同じく、生徒 1 人分に足りない数は赤、2 人分に足りない数は青、2 人分以上は緑で出ます。
- 装備タブの「全体」では部位ごとに T1〜T10 の装備、T2〜T10 の設計図、万能設計図の順に並び、左下に「T6」のようなティアが付きます。「設計図」では部位ごとに 1 行で、T1 の装備、T2〜T10 の設計図、万能設計図の個数が並びます。
- 「強化素材」では強化珠・スプリング・ハンマー・銃身・撃針が 1 行ずつ、初級から最上級の順に並びます。右端に、生徒何人分かとその計算式が出ます（お仕事タブと同じ数です）。
  - 強化珠は、生徒 1 人の装備 3 部位を T1〜T10 まで上げる分で数えます。
  - スプリング・ハンマー・銃身・撃針は、固有武器 1 本を上限まで上げる分で数えます。スプリング・ハンマー・銃身は、合う武器種の固有武器が 1.5 倍の経験値で受け取ります。

</details>

## 生徒

1. ホームの下の「生徒」から誰か 1 人を選び、右側の「基本情報」タブを開く
2. 画面の左右の端の「＜」「＞」で、1 人ずつ 1 秒ほど止めながら送る

<details markdown="1">
<summary>生徒タブの見方</summary>

| 列       | 意味                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------- |
| 育成     | 印を付けると、育成タブで必要な素材を計算します（[育成タブの使い方](plan.md)）                                     |
| Lv       | レベル                                                                                                            |
| 星       | ゲームと同じ★の絵。★1〜★4 は黄色い★、その上は固有武器の青い★（★5 は青い★ 1 個）。マウスを乗せると固有武器のレベル |
| スキル   | EX スキルのレベル、続けてほかの 3 つ。最大（Lv10）は M。例: `5M7M`                                                |
| 装備     | 3 つの装備のティア。例: `T10/9/8`。レベルは読まず、そのティアの最大とみなします                                   |
| 愛用品   | 愛用品のティア。ない生徒は —                                                                                      |
| 能力解放 | 能力解放の 3 つのレベル                                                                                           |
| 絆       | 絆ランク                                                                                                          |

- 読み取れなかった項目は「?」になります。もう一度その生徒を表示すると埋まります。
- 「レベルアップ」「神秘解放」タブを開いているときも、名前とレベルは読みます。レベルを上げた生徒は、「基本情報」に戻らなくても新しいレベルになります。
- タブの名前の横の数（「生徒 42」）は、読めた人数です。ゲームの所持人数と比べると、読み漏れがないか分かります。名前を読めなかった生徒は数えません。
- 生徒はレベルの高い順、同じなら星の高い順、その次に絆の高い順に並びます。列の見出しを押すと、その列の高い順に並べ替えます。

</details>

## ショップ

1. ホームの下の「ショップ」で、総力戦・大決戦・カケラ(文字)・合同火力演習・指名手配・熟達証書 のどれかを選ぶ
2. 右側の品物を一番下までゆっくりスクロールする（買い切った品は一番下にあります）

<details markdown="1">
<summary>ショップタブの見方</summary>

- 店の名前を押すと開きます。名前の横の時刻は、その店のコインの所持数か品物を最後に読み取って変わった時刻です。名前の右に、その店のコインの所持数が出ます。
- 品物は、買う価値の高い順（秘伝ノート、神名のカケラ、生徒の神名文字、テイラーストーン、BD、技術ノート、オーパーツ…）に並びます。全部買い切った品は一番下で灰色になります。
- 品物の下に、コインのアイコンと「残り回数@値段」（例: `40回@10`）か「売切れ」が出ます。総力戦と大決戦は、上の行が通常コイン、下の行がレアコインです。
- カケラ(文字) 以外の店は、毎月 1 日の午前 4 時に残り回数が戻ります。それより前に読んだ店には「前の月の値」と出るので、もう一度読ませてください。
- 通常・青輝石・カケラ(その他)・戦術対抗戦 の店は読みません。

</details>

## クレジット

ゲームの画面の上にあるクレジットは、表示されている画面ならどこでも読みます。育成タブの計算や、お仕事タブの特別依頼に使います。
