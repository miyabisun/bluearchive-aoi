# ゲームの画面を読ませる

Aoi はゲームの画面に映っているものを読み取って数えます。読ませたい画面をゲームで開き、
ゆっくりスクロールしたり送ったりするだけです。Aoi の側で操作することはありません。

準備: Aoi とブルーアーカイブを起動しておきます。スマホで遊ぶときは、スマホの画面を Aoi に送っておきます
（[Android](android.md)、[iPhone](stream.md)）。Aoi の入手と起動のしかたは
[README](../../README.md#ダウンロードと起動) にあります。読み終えると、Aoi のアイテム・装備・生徒・ショップの
各タブに、ゲームと同じ数が並ぶようになります。

読み取りがうまくいっているかは、Aoi の右上の表示（バッジ）で分かります。
「アイテムを集計中」のように出ていれば読めています。意味は
[困ったとき](trouble.md#右上の表示の意味) にまとめてあります。

> [!TIP]
> PC 版では、ほかのウィンドウがゲームに重なっていても読めます。ゲームを最小化すると読めません。

## アイテムと装備

1. ゲームのホーム画面で、右上のメニューボタン（≡）を押します。
2. 「アイテム」を押します。装備を読ませるときは「装備」を押します。
3. 右側の「リスト」の上にある並び順を確かめます。左が「デフォルト」、右の矢印のボタンが
   上向き（≡↑）になっていれば大丈夫です。違うときは、押して「デフォルト」と上向きに戻します。
   Aoi はこの並び順のときだけ数えます。ほかの並び順では、右上に「対象外の画面」と出ます。
4. リストをマウスのホイール（スマホでは指）で上から下まで少しずつスクロールします。
   1 回スクロールしたら一瞬止まる、を繰り返すと確実です。同じ数を 3 回続けて読めたときに
   数を決めるので、速く流しすぎると読み飛ばします。
5. Aoi の「アイテム」タブ（装備は「装備」タブ）に、アイコンと個数が並びます。

Aoi の画面では次のことができます。

- アイコンにマウスを乗せると、名前が出ます。
- 「名前で検索」に入力すると、そのアイテムだけに絞れます。ひらがなで入力しても、
  カタカナの名前が見つかります。
- 装備タブでは部位ごとに T1〜T10 の装備、T2〜T10 の設計図、万能設計図の順に並び、
  左下に「T6」のようなティアが付きます。

覚えておくと良いことは次のとおりです。

- 個数が 1 万以上のものは、ゲームと同じく「51K」のように千単位で出ます。
- ゲームでアイテムを使い切ると、ゲームの一覧から消えます。Aoi からは、そのアイテムの
  前後が並んで見えたときに消えます。一覧の最初の方のアイテムなら、一番上までスクロールしたときです。
- イベントのアイテム（イベントのポイントやバレンタインのチョコなど）は数えません。

## 生徒

1. ゲームのホーム画面の下にある「生徒」を押し、一覧から誰か 1 人を選びます。
2. 生徒の画面で、右側の「基本情報」タブを開きます。
3. 画面の左右の端にある「＜」「＞」で、生徒を 1 人ずつ送ります。1 人ごとに 1 秒ほど
   止めると確実です。
4. Aoi の「生徒」タブに、読めた生徒が並びます。

生徒タブの見方は次のとおりです。

| 列       | 意味                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 育成     | 印を付けると、育成タブで必要な素材を計算します（[育成タブの使い方](plan.md)）            |
| Lv       | レベル                                                                                   |
| 星       | ★1〜★4、その上は固有武器の 固有1〜固有4（★5 は 固有1）。マウスを乗せると固有武器のレベル |
| スキル   | EX スキルのレベル、続けてほかの 3 つ。最大（Lv10）は M。例: `5M7M`                       |
| 装備     | 3 つの装備のティア。例: `T10/9/8`。レベルは読まず、そのティアの最大とみなします          |
| 愛用品   | 愛用品のティア。ない生徒は —                                                             |
| 能力解放 | 能力解放の 3 つのレベル                                                                  |
| 絆       | 絆ランク                                                                                 |

- 読み取れなかった項目は「?」になります。もう一度その生徒を表示すると埋まります。
- 「レベルアップ」「神秘解放」タブを開いているときも、名前とレベルは読みます。
  レベルを上げた生徒は、「基本情報」に戻らなくても新しいレベルになります。
- タブの名前の横の数（「生徒 42」）は、読めた人数です。ゲームの所持人数と比べると、
  読み漏れがないか分かります。名前を読めなかった生徒は数えません。
- 生徒はレベルの高い順、同じなら星の高い順、その次に絆の高い順に並びます。列の見出しを
  押すと、その列の高い順に並べ替えます。

## ショップ

1. ゲームのホーム画面の下にある「ショップ」を押します。
2. 左のメニューから、総力戦・大決戦・カケラ(文字)・合同火力演習・指名手配・熟達証書 の
   どれかを選びます。
3. 右側の品物を一番下までゆっくりスクロールします。買い切った品は一番下にあります。
4. Aoi の「ショップ」タブに、店ごとに並びます。店の名前を押すと開きます。

ショップタブの見方は次のとおりです。

- 店の名前の右に、その店のコインの所持数が出ます。
- 品物は、買う価値の高い順（秘伝ノート、神名のカケラ、生徒の神名文字、テイラーストーン、
  BD、技術ノート、オーパーツ…）に並びます。全部買い切った品は一番下で灰色になります。
- 品物の下に、コインのアイコンと「残り回数@値段」（例: `40回@10`）か「売切れ」が出ます。
  総力戦と大決戦は、上の行が通常コイン、下の行がレアコインです。
- カケラ(文字) 以外の店は、月が変わると残り回数が戻ります。前の月に読んだ店には
  「前の月の値」と出るので、もう一度読ませてください。
- 通常・青輝石・カケラ(その他)・戦術対抗戦 の店は読みません。

## クレジット

ゲームの画面の上にあるクレジットは、表示されている画面ならどこでも読みます。
育成タブの計算や、お仕事タブの特別依頼に使います。
