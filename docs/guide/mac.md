# macOS で初めて開く

macOS 版の Aoi は Apple の公証（ノータリゼーション）を受けていないため、初めて開くときに
macOS が起動を止めます。一度だけ次の手順で許可すると、以後はふつうに開けます。
手順は Apple の [開発元が不明な Mac アプリを開く](https://support.apple.com/ja-jp/guide/mac-help/mh40616/mac)
に沿っています。

ブルーアーカイブの PC 版は Windows 専用なので、macOS 版はスマホから送った画面を読みます
（[Android のスマホの画面を読む](android.md)、iPhone は [配信アプリでスマホの画面を送る](stream.md)）。
スマホがつながるまでは、右上に「取り込み元なし」と出ます。

## 入れる

1. [最新版のリリースページ](https://github.com/miyabisun/bluearchive-aoi/releases/latest) の「Assets」から
   `bluearchive-aoi-universal-apple-darwin.dmg` をダウンロードします。
   Apple シリコンと Intel のどちらの Mac 向けにも、このファイル 1 つです。
2. ダウンロードしたファイルを開き、出てきた `bluearchive-aoi` を「アプリケーション」フォルダへ
   ドラッグします。

## 初めて開く（macOS 13 Ventura 以降）

1. 「アプリケーション」フォルダの `bluearchive-aoi` をダブルクリックします。
   開けないという表示が出たら、その表示を閉じます。「ゴミ箱に入れる」は押しません。
2. アップルメニュー ＞「システム設定」を開き、サイドバーの「プライバシーとセキュリティ」を押します。
3. 「セキュリティ」の欄まで下にスクロールし、`bluearchive-aoi` について出ている
   「開く」（版によっては「このまま開く」）を押します。
   このボタンは、手順 1 で開こうとしてから約 1 時間だけ出ます。消えていたら手順 1 からやり直します。
4. 確認が出たら「このまま開く」を押します。
5. Mac のログインパスワードを入れて「OK」を押します。

macOS 13 Ventura と 14 Sonoma では、Finder からも開けます。`bluearchive-aoi` を Control キーを
押しながらクリックして「開く」を選び、出てきた確認で「開く」を押します。

## macOS 12 Monterey 以前

手順 2・3 は、アップルメニュー ＞「システム環境設定」＞「セキュリティとプライバシー」＞「一般」にある
「このまま開く」を押します。

## 新しい版にする

Aoi の右上の「≡」から「アップデートを確認」を押します。新しい版があると「入手ページを開く」のボタンが
出ます。押して開いたページから、上の「入れる」と同じように入れ直します。「アプリケーション」フォルダの古い
`bluearchive-aoi` は置き換えます。新しい版も、初めて開くときに上の許可を求められることがあります。
