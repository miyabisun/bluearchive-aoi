# 育成タブの使い方

育成タブでは育てたい生徒を目標まで育てるのに必要な素材を計算し、手持ちとの過不足を出します。
足りない分を、選択ボックス・神名のカケラ・ショップのどれで補うかを選んで、払った後の残りを確かめられます。

準備: Aoi を起動し、アイテム・装備・生徒・ショップを読ませておきます（[ゲームの画面を読ませる](reading.md)）。
読ませていないものは「所持 0」として計算され、生徒を読ませていないと育成タブには何も出ません。

## 育てる生徒を選ぶ

1. Aoi の「生徒」タブで、育てたい生徒の「育成」の列に印を付けます。
2. 「育成」タブを開くと、印を付けた生徒が「既存の生徒一覧」に並びます。

印を外すと、育成タブからも消えます。育成タブで生徒名の左にある赤い × を押しても外せます。

## 目標を決める（既存の生徒一覧）

生徒ごとに、Lv・星・スキル（EX・N・P・S）・装備（3 つ）の目標が並びます。最初は
Lv90、スキル 5/10/10/10、装備 T10/10/10 です。

- 欄を押して、数字を入力するか、キーボードの ↑ ↓ で変えます。
- 欄の上の小さな数字はいまの値です。
- 星はゲームと同じ★の絵で出ます（★1〜★4 は黄色、固有1〜固有4 は固有武器の青。★5 は 青い★ 1 個）。目標の★を押すと
  ★の一覧が開くので、選びます。いまの星より下は選べません。選ばないうちは、いまの星のままです。
- 目標はアプリを閉じても残ります。

右の「再読込」については、[計算はいつ新しくなるか](#計算はいつ新しくなるか) を見てください。

## 必要素材

目標までに要るものを、全員分まとめて出します。

- クレジット（M は 100 万）、レポートの経験値、強化珠の経験値、そのほかの素材や設計図が、
  「必要・所持・過不足」で並びます。足りれば緑の「足りる」、足りなければ赤の「不足 N」です。
- 技術ノート・BD・オーパーツは、種類ごとに 1 行で、初級〜最上級が左から 灰・青・黄・紫 の
  マスに並びます。マスには「必要数 / 所持数」が出て、足りれば緑、足りなければ赤です。
  アイコンにマウスを乗せると名前が出ます。
- 装備の設計図は部位ごとの表にまとめます。左が部位（T1 の装備のアイコン）で、T2〜T10 の列の
  マスに「必要数 / 所持数」が出ます（要らないティアは空です）。
  - T2〜T9 はその設計図を持っている分から払い、残りは同じ部位の万能設計図で払う前提です。
    足りなくても赤くなりません。
  - T10 は、万能設計図で払うと 1 枚に 50 枚かかるので、自動では払いません。足りなければ赤くなり、
    「不足分の調達」に出ます。
  - 表の下の行「T2 - T9:」に、T2〜T9 の残りに使う万能設計図の枚数と所持数が「必要数 / 所持数」で出ます。
    足りれば緑、足りなければ赤で、足りない分は「不足分の調達」にも出ます。
- 読めていない値があって数えられなかったものは、「○○: Lv は数えられません」のように出ます。
- レベルの途中の経験値は読まないので、必要な数は少し多めに出ることがあります。
  装備は今のティアを最大レベルとみなし、次のティアから Lv1 で受け取って最大まで強化する計算です。

## 不足分の調達

足りないものをどの持ち物やショップで補うかを試すところです。ここで払っても、ゲームのアイテムや
コインは減りません。決めた内容を見ながら、ゲームの中で箱を開けたりショップで買ったりします。

足りないものごとに 2 行で出ます。

- 1 行目: 足りないもの、不足の数、残り（払った後に残る不足。0 になると緑）
- 2 行目: 補うのに使えるもの（チップ）。アイコンと、その持ち物の数が出ます。

チップになるのは次のものです。

- 選択ボックス（アイテム一覧で読んだ数）。同じ見た目の箱がありますが、マウスを乗せると
  「6 種から 1 つ」「12 種から 1 つ」のように選べる数が分かります。
- 神名のカケラ（生徒の神名文字が足りないとき）。カケラ(文字) の店で読んだその生徒の交換レートから、
  20 文字ごとにレートが上がる計算です（5 カケラで止まります）。
- 今月読んだショップの品。コインのアイコンが出ます（指名手配コインも出ます）。
- T10 設計図の不足には、T10装備設計図選択ボックスと、その部位の万能設計図（T10 設計図 1 枚に 50 枚）。
  万能設計図のチップの数は T2〜T9 に使った残りです。

チップの操作は次のとおりです。

| 操作                | 動き                                          |
| ------------------- | --------------------------------------------- |
| クリック            | 1 つ払う                                      |
| 右クリック          | 1 つ戻す                                      |
| Shift + クリック    | その行の不足がなくなるまで払う                |
| Shift + 右クリック  | そのチップで払った分を全部戻す                |
| 押し続ける          | キーの長押しのように、続けて払う（戻す）      |
| Enter / Delete キー | 1 つ払う / 1 つ戻す（キーボードで選んだとき） |

- 払った分はチップに「+N」と出ます。チップの数はすべての行で払った後の残りです。
- 選択ボックス・コイン・万能設計図は、持っている数より多く払えます（マイナスになります）。
  テイラーメイドで箱を作るなど、あとで用意するつもりの分を見込めます。
- ショップは今月の残り回数までしか買えません。使い切ると、チップが灰色の「売切れ」になります。
- テイラーメイドで作る箱や、お仕事・スケジュールで手に入る分は、ここには出ません。

### 精算

何か払うと、下に「精算」が出ます。払ったものごとに、所持・消費（赤）・残りが並びます。
残りは 0 より多ければ緑、マイナスなら赤です。

「リセット」を押すと、払った分を全部取り消します。

## 計算はいつ新しくなるか

育成タブは、Aoi を起動したとき、または「再読込」を押したときの読み取り結果で計算します。
そのあとゲームで生徒を強化したり素材を使ったりしても、育成タブの数と払った分はそのままです。
強化しながら確かめたいときに、計画が消えないようにするためです。

- 最新の状態で計算し直したいときは、「既存の生徒一覧」の右の「再読込」を押します。
  払った分は取り消されます。
- 目標を変えたときは、それまでと同じ読み取り結果で計算し直します。
