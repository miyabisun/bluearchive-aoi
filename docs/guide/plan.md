# 育成タブの使い方

育てたい生徒に印を付けると、足りない素材と、その補い方が出ます。

<div class="movie" data-spec="plan"></div>

1. 生徒タブで、育てたい生徒の「育成」に印を付ける
2. 育成タブで、Lv・星・スキル・装備の目標を決める
3. 「必要素材」で、足りないものを見る
4. 「不足分の調達」で、箱・カケラ・ショップの品を押して補う
5. 「精算」の残りを見ながら、ゲームで箱を開けて店で買う

- 先に、アイテム・装備・生徒・ショップを[読ませておきます](reading.md)。生徒を読ませていないと、何も出ません。
- ここで払っても、ゲームのアイテムやコインは減りません。

<details markdown="1">
<summary>目標の決め方</summary>

- 印を付けた生徒が「既存の生徒一覧」に並びます。印を外すか、名前の左の赤い × を押すと消えます。
- 目標は Lv・星・スキル（EX・N・P・S）・装備（3 つ）です。
- 最初は Lv90、スキル 5/10/10/10、装備 T10/10/10 です。
- 欄を押して数字を入れるか、↑ ↓ で変えます。欄の上の小さな数字は、いまの値です。
- 星は、目標の★を押すと一覧が開くので選びます。いまの星より下は選べません。選ばないうちは、いまの星のままです。
- 星はゲームと同じ★の絵です（★1〜★4 は黄色、固有1〜固有4 は固有武器の青。★5 は青い★ 1 個）。
- 目標は、アプリを閉じても残ります。

</details>

<details markdown="1">
<summary>必要素材の見方と計算</summary>

目標までに要るものを、全員分まとめて出します。読ませていないものは「所持 0」です。

| 行                                                   | 出方                                                                   |
| ---------------------------------------------------- | ---------------------------------------------------------------------- |
| クレジット・レポート・強化珠・そのほかの素材や設計図 | 「必要・所持・過不足」。足りれば緑の「足りる」、なければ赤の「不足 N」 |
| 技術ノート・BD・オーパーツ                           | 種類ごとに 1 行。マスに「必要数 / 所持数」（足りれば緑、なければ赤）   |
| 装備の設計図                                         | 部位ごとの表。T2〜T10 のマスに「必要数 / 所持数」                      |

- クレジットの M は 100 万です。レポートと強化珠は経験値で数えます。
- 技術ノート・BD・オーパーツのマスは、初級〜最上級が左から 灰・青・黄・紫 です。アイコンにマウスを乗せると名前が出ます。
- 設計図の表の左は部位（T1 の装備のアイコン）です。要らないティアのマスは空です。

設計図の払い方は、ティアで違います。

| ティア | 払い方                                                | 足りないとき                     |
| ------ | ----------------------------------------------------- | -------------------------------- |
| T2〜T9 | その設計図から払い、残りは同じ部位の万能設計図で払う  | マスは赤くならない               |
| T10    | 自動では払わない（万能設計図だと 1 枚に 50 枚かかる） | 赤くなり、「不足分の調達」に出る |

- 表の下の行「T2 - T9:」に、T2〜T9 の残りに使う万能設計図が「必要数 / 所持数」で出ます。足りれば緑、足りなければ赤です。足りない分は「不足分の調達」にも出ます。
- 読めていない値があって数えられなかったものは、「○○: Lv は数えられません」のように出ます。
- レベルの途中の経験値は読まないので、必要な数は少し多めに出ることがあります。
- 装備は、今のティアを最大レベルとみなします。次のティアから Lv1 で受け取り、最大まで強化する計算です。

</details>

<details markdown="1">
<summary>不足分の調達で使えるものと操作</summary>

足りないものごとに 2 行で出ます。

| 行     | 中身                                                         |
| ------ | ------------------------------------------------------------ |
| 1 行目 | 足りないもの、不足の数、残り（払った後の不足。0 になると緑） |
| 2 行目 | 補うのに使えるもの（チップ）。アイコンと、その持ち物の数     |

チップになるもの

| チップ                    | 出るとき・数え方                                                                                                    |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 選択ボックス              | アイテム一覧で読んだ数。同じ見た目の箱は、マウスを乗せると「6 種から 1 つ」「12 種から 1 つ」のように選べる数が出る |
| 神名のカケラ              | 生徒の神名文字が足りないとき                                                                                        |
| ショップの品              | 今月読んだ店の品。コインのアイコンが出る（指名手配コインも）                                                        |
| T10装備設計図選択ボックス | T10 設計図が足りないとき                                                                                            |
| 万能設計図                | T10 設計図が足りないとき（その部位のもの。T10 設計図 1 枚に 50 枚）                                                 |

- 神名のカケラは、カケラ(文字) の店で読んだその生徒の交換レートで数えます。20 文字ごとにレートが上がり、5 カケラで止まります。
- 万能設計図のチップの数は、T2〜T9 に使った残りです。

| 操作                | 動き                                          |
| ------------------- | --------------------------------------------- |
| クリック            | 1 つ払う                                      |
| 右クリック          | 1 つ戻す                                      |
| Shift + クリック    | その行の不足がなくなるまで払う                |
| Shift + 右クリック  | そのチップで払った分を全部戻す                |
| 押し続ける          | キーの長押しのように、続けて払う（戻す）      |
| Enter / Delete キー | 1 つ払う / 1 つ戻す（キーボードで選んだとき） |

- 払った分は、チップに「+N」と出ます。チップの数は、すべての行で払った後の残りです。
- 選択ボックス・コイン・万能設計図は、持っている数より多く払えます（マイナスになります）。テイラーメイドで作る箱など、あとで用意する分を見込めます。
- ショップは、今月の残り回数までしか買えません。使い切ると、チップが灰色の「売切れ」になります。
- テイラーメイドで作る箱や、お仕事・スケジュールで手に入る分は、ここには出ません。

何か払うと、下に「精算」が出ます。

- 払ったものごとに、所持・消費（赤）・残りが並びます。残りは 0 より多ければ緑、マイナスなら赤です。
- 「リセット」を押すと、払った分を全部取り消します。

</details>

## 計算に使う数

<div class="movie" data-spec="fresh"></div>

| 数                                                         | いつの数か                             |
| ---------------------------------------------------------- | -------------------------------------- |
| 持ち物（アイテム・装備・クレジット・ショップの品とコイン） | いつも今の読み取り結果                 |
| 育成対象の育成状況                                         | Aoi の起動時か、「再読込」を押したとき |

<details markdown="1">
<summary>強化したとき、持ち物が変わったとき</summary>

- ゲームで生徒を強化しても、必要な数と払った分はそのままです。強化しながら確かめても、計画が消えないようにするためです。
- 持ち物が増えたり減ったりして読み取られると、所持数と不足がすぐ変わります。
- 払った分は残るので、払った後に所持数が減ると、残りがマイナスになることがあります。
- 育成対象の育成状況が変わって読み取られると、「既存の生徒一覧」の下にオレンジの文字が出ます。いつの読み取りで計算しているかと、変わった生徒の名前です。
- 「既存の生徒一覧」の右の「再読込」を押すと、今の育成状況で計算し直します。払った分は取り消されます。
- 目標を変えたときは、それまでと同じ育成状況で計算し直します。

</details>
