# 困ったとき

Aoi がうまく読めないときの確かめ方と、保存場所などをまとめています。

## 右上の表示の意味

| 表示                                        | 意味                                                                                   |
| ------------------------------------------- | -------------------------------------------------------------------------------------- |
| ゲーム未検出                                | ブルーアーカイブが起動していません                                                     |
| 対象外の画面                                | 読む対象ではない画面です。一覧の並び順が「デフォルト」の上向き以外のときもこうなります |
| アイテムを集計中 N fps / 装備を集計中 N fps | その一覧を、1 秒に N 回読んでいます                                                    |
| 生徒を集計中 N fps                          | 生徒の画面を読んでいます                                                               |
| ショップを集計中 N fps                      | ショップを読んでいます                                                                 |
| キャプチャ失敗                              | Windows がゲームの画面の取り込みを断りました。理由が下に出ます                         |
| 一時中断                                    | 読み取りを止めています                                                                 |

この表示を押すと、読み取りを一時中断できます（左のランプが赤になります）。もう一度押すと再開します。
一時中断している間は、パソコンの負担も小さくなります。

## 「ゲーム未検出」「キャプチャ失敗」のまま

- 「ゲーム未検出」のときは、ブルーアーカイブが起動しているか確かめてください。ゲームを起動すると、
  数秒で自動的に見つけます。
- 「キャプチャ失敗」のときは、下に Windows の返した理由が出ます。ゲームと Aoi を一度閉じて、
  起動し直してください。直らないときは、出ている理由を添えて
  [GitHub の Issues](https://github.com/miyabisun/bluearchive-aoi/issues) で知らせてください。

## 数が出てこない・増えない

- 右上が「対象外の画面」のままのときは、一覧の並び順を確かめてください。
  「デフォルト」の上向き（≡↑）のときだけ数えます。
- 速くスクロールすると読み飛ばします。少しずつスクロールして、そのたびに一瞬止めてください。
- ゲームを最小化すると読めません。ほかのウィンドウが重なっているのは大丈夫です。
- 読み取りを一時中断していないか、右上の表示を確かめてください。

## 生徒やショップが出てこない

生徒の名前とショップは、Windows の日本語の文字認識（光学式文字認識）で読みます。
入っていないと、生徒タブとショップタブに何も出ません。次の手順で確かめられます。

1. Windows の「設定」を開きます。
2. 「時刻と言語」→「言語と地域」を開きます。
3. 「日本語」の右の「…」を押し、「言語のオプション」を開きます。
4. 「言語の機能」に「光学式文字認識」があり、インストール済みになっていれば大丈夫です。
   ない場合は、このページから追加できます。

## 「?」が出る

その項目を確実に読めなかったしるしです。当て推量で数を出さないようにしています。
もう一度その画面を表示すると、読めた時点で埋まります。

## 読み取った内容の保存場所

- 最新の読み取り結果は、`ドキュメント\Aoi\aoi.yaml` に自動で保存されます。
- 右上の「≡」→「YAMLを書き出す」を押すと、その時点の内容を `ドキュメント\Aoi\aoi-日付-時刻.yaml`
  として残せます。
- 次に起動したときは、前回までの読み取り結果と、育成の目標を引き継いで始まります。
  この引き継ぎ用のデータは `%APPDATA%\io.github.miyabisun.bluearchive-aoi` にあります。

## 見た目を変えたい

右上の「≡」から、テーマを ライト・ダーク・自動（Windows の設定に合わせる）から選べます。

## 使うのをやめるとき

インストールはしていないので、ダウンロードした exe を削除するだけです。読み取り結果も消す
場合は、上の「読み取った内容の保存場所」にある 2 つのフォルダも削除してください。
