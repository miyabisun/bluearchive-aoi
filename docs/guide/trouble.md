# 困ったとき

Aoi がうまく読めないときの確かめ方と、保存場所などをまとめています。

## 右上の表示の意味

| 表示                            | 意味                                                                                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ゲーム未検出                    | PC 版のブルーアーカイブが起動しておらず、スマホの画面も届いていません                                                                                                           |
| 対象外の画面                    | 読む対象ではない画面です。一覧の並び順が「デフォルト」の上向き以外のときもこうなります                                                                                          |
| アイテムを集計中 / 装備を集計中 | その一覧を読んでいます                                                                                                                                                          |
| 生徒を集計中                    | 生徒の画面を読んでいます                                                                                                                                                        |
| ショップを集計中                | ショップを読んでいます                                                                                                                                                          |
| キャプチャ失敗                  | Windows がゲームの画面の取り込みを断りました。理由が下に出ます                                                                                                                  |
| 一時中断                        | 読み取りを止めています                                                                                                                                                          |
| 画面が小さすぎます              | ゲームが横幅およそ 1500 ピクセルより小さく描かれていて読めません。PC 版はウィンドウを広げ（フル HD の画面ならウィンドウ表示でも読めます）、スマホは配信の解像度を上げてください |
| 取り込み元なし                  | macOS 版で、スマホがつながっていません（[Android](android.md)、[iPhone](stream.md)）                                                                                            |

表示の左のアイコンは、いま画面を受け取っている先です。パソコンの形は PC 版のゲームのウィンドウ、スマホの形は
[Android](android.md)、電波の形は[配信アプリ](stream.md)です。表示にマウスを乗せると、受け取っている先（スマホなら
機種名と USB か Wi-Fi か）と、1 秒に何回読んでいるか（fps）が出ます。

この表示を押すと、読み取りを一時中断できます（左のアイコンが赤になります）。もう一度押すと再開します。
一時中断している間は、パソコンの負担も小さくなります。

## 「ゲーム未検出」「キャプチャ失敗」のまま

- 「ゲーム未検出」のときは、ブルーアーカイブが起動しているか確かめてください。ゲームを起動すると、
  数秒で自動的に見つけます。スマホで遊んでいるときは、スマホの画面を送れているか確かめてください
  （[Android](android.md)、[iPhone](stream.md)）。
- 「キャプチャ失敗」のときは、下に Windows の返した理由が出ます。ゲームと Aoi を一度閉じて、
  起動し直してください。直らないときは、出ている理由を添えて
  [GitHub の Issues](https://github.com/miyabisun/bluearchive-aoi/issues) で知らせてください。

## 数が出てこない・増えない

- 右上が「対象外の画面」のままのときは、一覧の並び順を確かめてください。
  「デフォルト」の上向き（≡↑）のときだけ数えます。
- 速くスクロールすると読み飛ばします。少しずつスクロールして、そのたびに一瞬止めてください。
- PC 版では、ゲームを最小化すると読めません。ほかのウィンドウが重なっているのは大丈夫です。
- 読み取りを一時中断していないか、右上の表示を確かめてください。

## 生徒やショップが出てこない

- 生徒は、ゲームで生徒の詳細画面を開いたときに読みます。名前を読めなかった生徒は出ません。
  Aoi の版より後に追加された生徒は名前を知らないため読めません。☰ の「アップデートを確認」で
  新しい版にしてください。
- ショップは、総力戦・大決戦・カケラ(文字)・合同火力演習・指名手配・熟達証書 の画面を開いたときに
  読みます。ほかのショップは読みません。

## 「?」が出る

その項目を確実に読めなかったしるしです。当て推量で数を出さないようにしています。
もう一度その画面を表示すると、読めた時点で埋まります。

## 読み取った内容の保存場所

- 最新の読み取り結果は、「ドキュメント」フォルダ（Mac では「書類」フォルダ）の中の `Aoi` フォルダに、`aoi.yaml` として自動で保存されます。
- 右上の「≡」→「YAMLを書き出す」を押すと、その時点の内容を同じフォルダに `aoi-日付-時刻.yaml`
  として残せます。
- 次に起動したときは、前回までの読み取り結果と、育成の目標を引き継いで始まります。
  この引き継ぎ用のデータは `%APPDATA%\io.github.miyabisun.bluearchive-aoi`（Mac では
  `~/Library/Application Support/io.github.miyabisun.bluearchive-aoi`）にあります。

## 見た目を変えたい

右上の「≡」から、テーマを ライト・ダーク・自動（Windows や macOS の設定に合わせる）から選べます。

## 使うのをやめるとき

Windows ではダウンロードした exe を、Mac では「アプリケーション」フォルダの `bluearchive-aoi` を
削除します。読み取り結果も消す場合は、上の「読み取った内容の保存場所」にある 2 つのフォルダも
削除してください。
