# 困ったとき

うまく読めないときは、まず Aoi の右上の表示を見ます。

<div class="movie" data-spec="status"></div>

## 右上の表示の意味

| 表示                  | 意味                                                                                           |
| --------------------- | ---------------------------------------------------------------------------------------------- |
| ゲーム未検出          | ゲームが起動しておらず、スマホの画面も届いていない                                             |
| 対象外の画面          | 読む対象ではない画面。一覧の並び順が違うときも                                                 |
| 指名手配 などの画面名 | お仕事タブに項目がある、数を読まない画面（[ついてくる画面](work.md#ゲームの画面についてくる)） |
| ○○を集計中            | アイテム・装備・生徒・ショップを読んでいる                                                     |
| キャプチャ失敗        | Windows が画面の取り込みを断った                                                               |
| 一時中断              | 読み取りを止めている                                                                           |
| 画面が小さすぎます    | ゲームの横幅がおよそ 1500 ピクセルより小さく、読めない                                         |
| 取り込み元なし        | macOS 版で、スマホがつながっていない                                                           |

表示を押すと一時中断し、もう一度押すと再開します。

<details markdown="1">
<summary>表示の左のアイコンと、マウスを乗せたときの表示</summary>

左のアイコンは、いま画面を受け取っている先です。

| アイコン     | 受け取っている先          |
| ------------ | ------------------------- |
| パソコンの形 | PC 版のゲームのウィンドウ |
| スマホの形   | [Android](android.md)     |
| 電波の形     | [配信アプリ](stream.md)   |

- 一時中断の間は、アイコンが赤になります。パソコンの負担も小さくなります。
- 表示にマウスを乗せると、受け取っている先と、1 秒に何回読んでいるか（fps）が出ます。スマホなら、機種名と、USB・Wi-Fi のどちらかも出ます。

</details>

## よくあること

当てはまる見出しを押すと、確かめ方が開きます。

<details markdown="1">
<summary>「ゲーム未検出」「取り込み元なし」のまま</summary>

- PC 版は、ブルーアーカイブが起動しているか確かめてください。起動すると、数秒で自動的に見つけます。
- スマホで遊んでいるとき（macOS 版はいつも）は、スマホの画面を送れているか確かめてください（[Android](android.md)・[iPhone](stream.md)）。

</details>

<details markdown="1">
<summary>「キャプチャ失敗」のまま</summary>

- 下に、Windows の返した理由が出ます。
- ゲームと Aoi を一度閉じて、起動し直してください。
- 直らないときは、出ている理由を添えて [GitHub の Issues](https://github.com/miyabisun/bluearchive-aoi/issues) で知らせてください。

</details>

<details markdown="1" id="画面が小さすぎます">
<summary>「画面が小さすぎます」と出る</summary>

- PC 版は、ゲームのウィンドウを広げます。フル HD の画面なら、ウィンドウ表示でも読めます。
- スマホは、配信の解像度を上げます。

</details>

<details markdown="1">
<summary>数が出てこない・増えない</summary>

| 確かめること                | 直し方                                             |
| --------------------------- | -------------------------------------------------- |
| 右上が「対象外の画面」      | 一覧の並び順を「デフォルト」の上向き（≡↑）にする   |
| 速くスクロールした          | 少しずつスクロールして、そのたびに一瞬止める       |
| ゲームを最小化した（PC 版） | 最小化をやめる。ほかのウィンドウが重なるのは大丈夫 |
| 右上が「一時中断」          | 表示を押して再開する                               |

</details>

<details markdown="1">
<summary>生徒やショップが出てこない</summary>

- 生徒は、ゲームで生徒の詳細画面を開いたときに読みます。名前を読めなかった生徒は出ません。
- Aoi のバージョンより後に追加された生徒は、名前を知らないので読めません。右上の ≡ で開く設定の「アップデートを確認」で、新しいバージョンにしてください。
- ショップは、総力戦・大決戦・カケラ(文字)・合同火力演習・指名手配・熟達証書 の画面を開いたときに読みます。ほかのショップは読みません。

</details>

<details markdown="1">
<summary>「?」が出る</summary>

その項目を確実に読めなかったしるしです。当て推量で数を出さないようにしています。もう一度その画面を表示すると、読めた時点で埋まります。

</details>

## 保存と設定

<details markdown="1">
<summary>読み取った内容の保存場所</summary>

| 何を                 | どこに                                                                   |
| -------------------- | ------------------------------------------------------------------------ |
| 最新の読み取り結果   | 「ドキュメント」（Mac は「書類」）の `Aoi` フォルダの `aoi.yaml`（自動） |
| その時点の控え       | 同じフォルダの `aoi-日付-時刻.yaml`（設定の「データを保存」を押す）      |
| 次の起動への引き継ぎ | `%APPDATA%\io.github.miyabisun.bluearchive-aoi`                          |

- Mac の引き継ぎ用のデータは `~/Library/Application Support/io.github.miyabisun.bluearchive-aoi` にあります。
- 次に起動したときは、前回までの読み取り結果と、育成の目標を引き継いで始まります。
- 設定は、右上の ≡ で開きます。

**復元する**

1. 設定の「データを復元」を押す（保存したファイルの一覧が出ます）
2. ファイルを選んで「復元して再起動」を押す

- 今のデータがそのファイルの内容に置き換わり、Aoi が起動し直します。
- 別の PC で続きから使うときは、保存したファイルをその PC の同じフォルダに置いてから復元します。
- v0.3.22 より前に書き出したファイルは復元できません。

**引き継ぎ用のデータが壊れていたとき**

- 起動時にその旨が赤字で出て、空の状態から始まります。
- 読めなかったファイルは上書きしません。同じフォルダに `state.broken-日付-時刻.json` という名前で残します。

</details>

<details markdown="1">
<summary>見た目を変えたい</summary>

右上の ≡ で開く設定で変えます。

| 設定               | 選べるもの                                                           |
| ------------------ | -------------------------------------------------------------------- |
| テーマ             | 自動（Windows や macOS の設定に合わせる）・ライト・ダーク            |
| お仕事の自動開閉   | する・しない（[お仕事タブの見方](work.md#ゲームの画面についてくる)） |
| マウスカーソル変更 | なし・青・赤・緑（Windows だけ）                                     |

**マウスカーソル変更**

- マウスカーソル（矢印）を、ゲームのカーソルに似た矢印に変えます。
- ゲームの設定でカーソルを目立たせると、Aoi が読むゲームの画面にカーソルが写り込んで邪魔になります。代わりにこちらを使ってください。
- ゲームの読み込み中などに Windows が出す「矢印と輪」のカーソルも、同じ矢印に歯車を添えたものに変わります。
- 変わるのは、Aoi を起動している間だけです。「なし」を選ぶか Aoi を閉じると、Windows のカーソルに戻ります。

</details>

<details markdown="1">
<summary>使うのをやめるとき</summary>

- Windows では、ダウンロードした exe を削除します。
- Mac では、「アプリケーション」フォルダの `bluearchive-aoi` を削除します。
- 読み取り結果も消す場合は、上の「読み取った内容の保存場所」にある 2 つのフォルダも削除してください。

</details>
