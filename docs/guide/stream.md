# 配信アプリでスマホの画面を送る

iPhone の画面を、配信アプリ [Moblin](https://apps.apple.com/app/moblin/id6466745933)（無料）から、同じ Wi-Fi の PC の Aoi に送ります。

<div class="movie" data-spec="stream"></div>

iPhone での動作は、まだ確かめていません。

## iPhone（Moblin）で送る

1. Aoi の右上の ≡ で設定を開き、「配信方法」の「配信アプリとの連携」を選ぶ
2. iPhone のカメラで、Aoi に出た QR コードを読み取り、Moblin で開く
3. Moblin の「Scenes」で、映像（Video source）を「Screen capture」にする（初回だけ）
4. コントロールセンターの画面収録を長押しし、Moblin を選んで開始する
5. Moblin の配信のボタンを押して、ブルーアーカイブを開く

- Aoi に「（スマホのアドレス）から画面を受け取っています」と出たら届いています。
- あとは PC と同じように、[一覧や生徒の画面を送ります](reading.md)。

<details markdown="1">
<summary>必要なものと、確かめた環境</summary>

| 必要なもの | 条件                                       |
| ---------- | ------------------------------------------ |
| iPhone     | Moblin を入れておく                        |
| PC         | Windows か Mac                             |
| Wi-Fi      | PC と同じ Wi-Fi（ゲスト用の Wi-Fi は不可） |

- ゲスト用の Wi-Fi のように、つながった機器どうしが通信できない回線では使えません。
- Aoi は、RTMP で届く H.264 の映像なら、どの配信アプリからでも受け取ります。
- iPhone、Moblin、ほかの配信アプリでは、まだ確かめていません。確かめたのは Aoi の受け取り方で、Windows の PC 上で、配信アプリの代わりの送信プログラムを使いました。
- QR コードを読み取ると、Moblin に「Aoi」という配信先が入ります。読み取りに向いた設定（H.264、2560x1440、50 Mbps、15 fps）になります。
- 手順 1 で、QR コードと `rtmp://` で始まる URL が出ます。
- 手順 4 は、Moblin を選んで「ブロードキャストを開始」を押します。
- Moblin の画面の名前は、英語表示のものです。
- Android のスマホは、配信アプリを入れずに USB か Wi-Fi でも送れます（[Android のスマホの画面を読む](android.md)）。

</details>

<details markdown="1">
<summary>Windows・Mac に許可を求められたとき</summary>

- Windows で「Windows セキュリティの重要な警告」が出たら、「プライベート ネットワーク」に印を付けて「アクセスを許可する」を押します。スマホからの画面を受け取るために必要です。
- Mac でネットワークの受信接続を許可するか聞かれたら、「許可」を押します。

</details>

<details markdown="1">
<summary>ほかの配信アプリで送る</summary>

1. 「配信アプリとの連携」の「ほかのアプリ」を押す（URL の QR コードに切り替わります）
2. 配信アプリの配信先（RTMP のサーバー）に、Aoi に出た URL をそのまま入れる
3. 映像の形式を H.264 にし、解像度とビットレートをできるだけ高くする
4. 配信を始めて、ブルーアーカイブを開く

- QR コードをスマホで読み取ると、URL を写せます。
- 画面が粗いと、小さな数字が読めません。

</details>

<details markdown="1">
<summary>待ち受けの終わり</summary>

| 待ち受けが終わるとき                       |
| ------------------------------------------ |
| 「配信アプリとの連携」の「やめる」を押した |
| 「配信方法」でほかを選んだ                 |
| 10 分間、何も届かなかった                  |

- 配信を止めても、10 分の間なら同じ URL のまま送り直せます。
- もう一度待ち受けると、新しい URL になります。QR コードを読み取り直します。
- 送れるのは、この PC と同じネットワークの機器からだけです。URL を知らない機器からの配信は断ります。

</details>

<details markdown="1">
<summary>うまくいかないとき</summary>

| 表示や様子                                 | 確かめること                                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| 配信を始めても Aoi が受け取らない          | PC とスマホが同じ Wi-Fi か。Windows のファイアウォールで Aoi を許可したか                       |
| H.264 でない映像（H.265 など）は読めません | 配信アプリの映像の形式を H.264 にします。Moblin では QR コードを読み取り直すと H.264 になります |
| 画面が横倒しで小さく届いています           | 配信アプリで縦向き（Portrait）の配信にします                                                    |
| キーの違う配信が届いたので断りました       | 古い URL のままです。QR コードを読み取り直します                                                |
| ポート 1935 で待ち受けられません           | ほかの配信ソフトが同じポートを使っています。そのソフトを閉じてから、もう一度待ち受けます        |
| 受け取っているのに「対象外の画面」のまま   | 画面が粗いと読めません。配信アプリの解像度とビットレートを上げます                              |

</details>
