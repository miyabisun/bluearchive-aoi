# 配信アプリでスマホの画面を送る

iPhone の画面を、配信アプリ [Moblin](https://apps.apple.com/app/moblin/id6466745933)（無料）から、同じ Wi-Fi の PC（Windows・Mac）の Aoi に送ります。

<div class="movie" data-spec="stream"></div>

## iPhone（Moblin）で送る

必要なもの: Moblin を入れた iPhone と、PC と同じ Wi-Fi（ゲスト用の Wi-Fi は不可）。

1. Aoi の右上の ≡ から「配信アプリとの連携」を押す（QR コードと `rtmp://` で始まる URL が出ます）
2. iPhone のカメラで QR コードを読み取り、Moblin で開く
3. Moblin の設定の「Scenes」で、使うシーンの映像（Video source）を「Screen capture」にする（初回だけ）
4. コントロールセンターで画面収録のボタンを長押しし、Moblin を選んで「ブロードキャストを開始」を押す
5. Moblin の配信のボタンを押して配信を始め、ブルーアーカイブを開く

Aoi に「（スマホのアドレス）から画面を受け取っています」と出たら届いています。あとは PC と同じように [一覧や生徒の画面を送ります](reading.md)。

<details markdown="1">
<summary>必要なものと、確かめた環境</summary>

- Aoi は RTMP で届く H.264 の映像なら、どの配信アプリからでも受け取ります。
- ゲスト用の Wi-Fi のように、つながった機器どうしが通信できない回線では使えません。
- iPhone、Moblin、ほかの配信アプリでは、まだ確かめていません。Aoi の受け取り方は Windows の PC 上で、配信アプリの代わりの送信プログラムを使って確かめています。
- QR コードを読み取ると、Moblin に「Aoi」という配信先が入り、読み取りに向いた設定（H.264、2560x1440、50 Mbps、15 fps）になります。Moblin の画面の名前は英語表示のものです。
- Android のスマホは、配信アプリを入れずに USB ケーブルか Wi-Fi で送ることもできます（[Android のスマホの画面を読む](android.md)）。

</details>

<details markdown="1">
<summary>Windows・Mac に許可を求められたとき</summary>

- Windows で「Windows セキュリティの重要な警告」が出たら、「プライベート ネットワーク」に印を付けて「アクセスを許可する」を押します。スマホからの画面を受け取るために必要です。
- Mac でネットワークの受信接続を許可するか聞かれたら、「許可」を押します。

</details>

<details markdown="1">
<summary>ほかの配信アプリで送る</summary>

1. 「配信アプリとの連携」の「ほかのアプリ」を押すと、URL の QR コードに切り替わります。
2. 配信アプリの配信先（RTMP のサーバー）に、Aoi に出た URL をそのまま入れます。QR コードをスマホで読み取ると、URL を写せます。
3. 映像の形式を H.264 にし、解像度とビットレートをできるだけ高くします。画面が粗いと、小さな数字が読めません。
4. 配信を始めて、ブルーアーカイブを開きます。

</details>

<details markdown="1">
<summary>待ち受けの終わり</summary>

待ち受けは、「配信アプリとの連携」の「やめる」を押すか、10 分間何も届かないと終わります。配信を止めても、10 分の間なら同じ URL のままで送り直せます。もう一度待ち受けると新しい URL になるので、QR コードを読み取り直します。

送れるのは、この PC と同じネットワークの機器からだけです。URL を知らない機器からの配信は断ります。

</details>

<details markdown="1">
<summary>うまくいかないとき</summary>

| 表示や様子                                 | 確かめること                                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| 配信を始めても Aoi が受け取らない          | PC とスマホが同じ Wi-Fi か。Windows のファイアウォールで Aoi を許可したか                       |
| H.264 でない映像（H.265 など）は読めません | 配信アプリの映像の形式を H.264 にします。Moblin では QR コードを読み取り直すと H.264 になります |
| 画面が横倒しで小さく届いています           | 配信アプリで縦向き（Portrait）の配信にします                                                    |
| キーの違う配信が届いたので断りました       | 古い URL のままです。QR コードを読み取り直します                                                |
| ポート 1935 で待ち受けられません           | ほかの配信ソフトが同じポートを使っています。そのソフトを閉じてから、もう一度待ち受けます        |
| 受け取っているのに「対象外の画面」のまま   | 画面が粗いと読めません。配信アプリの解像度とビットレートを上げます                              |

</details>
