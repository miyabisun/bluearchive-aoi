# Android のスマホの画面を読む

Android 版の画面を、USB か Wi-Fi で PC の Aoi に送ります。スマホにアプリは入れません。

<div class="movie" data-spec="android"></div>

## 初めてつなぐ

1. スマホの「設定」→「デバイス情報」→「ビルド番号」を 7 回タップする
2. Aoi の右上の ≡ で設定を開き、「配信方法」の「Androidとの通信」を選ぶ
3. USB か Wi-Fi でつなぐ（下の表）
4. Aoi に「（機種名）の画面を USB で受け取っています」と出たら完了

|       | スマホでオンにする  | つなぎ方                                              |
| ----- | ------------------- | ----------------------------------------------------- |
| USB   | USB デバッグ        | ケーブルでつなぎ、スマホに出た確認で「許可」を押す    |
| Wi-Fi | ワイヤレス デバッグ | その項目を開き、ペア設定で Aoi の QR コードを読み取る |

- あとは PC と同じように、[一覧や生徒の画面を送ります](reading.md)。
- 2 回目からは、つなぐだけで自動でつながります。

<details markdown="1">
<summary>つなぎ方を細かく</summary>

- 手順 1 で「開発者向けオプション」が出ます。「USB デバッグ」と「ワイヤレス デバッグ」はその中にあります。
- USB: スマホに「USB デバッグを許可しますか？」と出ます。「このパソコンからの USB デバッグを常に許可する」に印を付けて「許可」を押します。
- Wi-Fi: 「ワイヤレス デバッグ」の項目を開き、「QR コードによるデバイスのペア設定」を押して読み取ります。スマホのカメラアプリではなく、この画面から読み取ります。
- Wi-Fi なら、手順 4 の表示は「（機種名）の画面を Wi-Fi で受け取っています」です。
- 2 回目からは、USB でつなぐか「ワイヤレス デバッグ」をオンにすれば、自動でつながります。
- ターミナルを開く必要はありません。

</details>

<details markdown="1">
<summary>必要なもの、USB と Wi-Fi の違い、確かめた環境</summary>

| 必要なもの | 条件                                       |
| ---------- | ------------------------------------------ |
| スマホ     | Android 11 以降。タブレットでも使える      |
| PC         | Windows か Mac                             |
| USB        | データを送れるケーブル（充電専用は不可）   |
| Wi-Fi      | PC と同じ Wi-Fi（ゲスト用の Wi-Fi は不可） |

|       | よいところ                 | 気をつけること                                   |
| ----- | -------------------------- | ------------------------------------------------ |
| USB   | つなげばすぐ使え、安定する | ケーブルが要る                                   |
| Wi-Fi | ケーブルが要らない         | 一度 QR コードでペア設定する。切れたらオンに戻す |

- ゲスト用の Wi-Fi のように、つながった機器どうしが通信できない回線では使えません。
- スマホの「ワイヤレス デバッグ」は、Wi-Fi が切れるなどすると止まります。そのつどオンに戻します。
- 両方つながるときは、USB を使います。
- 画面の名前は Pixel のものです。機種によって少し違います。
- 確かめたのは、Windows の PC と Legion Tab Y700（USB）です。
- Wi-Fi は、今の画面の受け取り方ではまだ確かめていません。Mac での動作も確かめていません。
- 配信アプリから送ることもできます（[配信アプリでスマホの画面を送る](stream.md)）。

</details>

<details markdown="1">
<summary>Windows・Mac に許可を求められたとき</summary>

- Windows で「Windows セキュリティの重要な警告」が出たら、「アクセスを許可する」を押します。スマホを Wi-Fi で探すために必要です。
- Mac でローカルネットワークの利用の許可を求められたら、許可します。

</details>

<details markdown="1">
<summary>切断と、スマホの電池</summary>

- 切るには、設定の「配信方法」の「Androidとの通信」の下にある「切断」を押します。「配信方法」でほかを選んでも切れます。次に Aoi を起動しても、自分で「接続」を押すまでつなぎません。
- スマホの電池を使います。読ませないときは、右上の表示を押して一時中断するか、切断してください。一時中断の間は画面を受け取りません。
- 受け取っている間、スマホは画面を動画にして送ります。長い辺 1920 ピクセルまで、毎秒 5 枚までです（画面が止まっていれば毎秒 0.1〜0.2MB ほど）。
- そのために、スマホへ小さなプログラム（scrcpy のサーバー、約 0.7MB）を置きます。
- Wi-Fi のペア設定をやめるときは、スマホの「ワイヤレス デバッグ」の「ペア設定済みのデバイス」から「Aoi」を選んで削除します。

</details>

<details markdown="1">
<summary>うまくいかないとき</summary>

| 表示や様子                          | 確かめること                                                                   |
| ----------------------------------- | ------------------------------------------------------------------------------ |
| USB でつないでも進まない            | 「USB デバッグ」がオンか。データを送れるケーブルか。スマホに許可が出ていないか |
| QR コードを読み取っても進まない     | PC とスマホが同じ Wi-Fi か。ゲスト用の Wi-Fi ではないか                        |
| 「（機種名）を探しています…」のまま | ケーブルがつながっているか、スマホの「ワイヤレス デバッグ」がオンか            |
| 「ペア設定できませんでした」        | 「もう一度」を押して、新しい QR コードを読み取り直す                           |

USB では、PC で Android Studio などの `adb` が動いていると、Aoi がスマホをつかめないことがあります。そのときは `adb` を止めてください。

</details>
