# Android のスマホの画面を読む

Android 版の画面を、USB ケーブルか Wi-Fi で PC（Windows・Mac）の Aoi に送ります。スマホにアプリを入れたり、ターミナルを開いたりする必要はありません。

<div class="movie"></div>

## 初めてつなぐ

必要なもの: Android 11 以降のスマホと、データを送れる USB ケーブルか、PC と同じ Wi-Fi（ゲスト用の Wi-Fi は不可）。

1. スマホの「設定」→「デバイス情報」→「ビルド番号」を 7 回タップする（開発者向けオプションが出ます）
2. Aoi の右上の ≡ から「Androidとの通信」を押す
3. USB か Wi-Fi でつなぐ
   - USB: 「開発者向けオプション」の「USB デバッグ」をオンにして、ケーブルで PC につなぎます。スマホに「USB デバッグを許可しますか？」と出たら、「このパソコンからの USB デバッグを常に許可する」に印を付けて「許可」を押します。
   - Wi-Fi: 「ワイヤレス デバッグ」をオンにして、その項目を開きます。「QR コードによるデバイスのペア設定」を押して、Aoi に出た QR コードを読み取ります（スマホのカメラアプリではなく、この画面から読み取ります）。
4. Aoi に「（機種名）の画面を USB で受け取っています」（Wi-Fi なら「Wi-Fi で」）と出たら、つながっています

あとはブルーアーカイブを開いて、PC と同じように [一覧や生徒の画面を送ります](reading.md)。2 回目からは、USB でつなぐか「ワイヤレス デバッグ」をオンにすれば、自動でつながります。

<details markdown="1">
<summary>USB と Wi-Fi の違い、確かめた環境</summary>

- タブレットでも使えます。充電専用の USB ケーブルでは使えません。ゲスト用の Wi-Fi など、つながった機器どうしが通信できない回線では使えません。
- USB はつなげばすぐに使え、Wi-Fi より安定しています。Wi-Fi はケーブルが要りませんが、スマホの「ワイヤレス デバッグ」は Wi-Fi が切れるなどすると止まるので、そのつどオンに戻します。一度 QR コードでペア設定しておく必要があります。両方つながるときは USB を使います。
- 画面の名前は Pixel のものです。機種によって少し違います。
- Windows の PC と Legion Tab Y700（USB）で確かめています。Wi-Fi は今の画面の受け取り方ではまだ確かめておらず、Mac での動作も確かめていません。
- 配信アプリから送ることもできます（[配信アプリでスマホの画面を送る](stream.md)）。

</details>

<details markdown="1">
<summary>Windows・Mac に許可を求められたとき</summary>

- Windows で「Windows セキュリティの重要な警告」が出たら、「アクセスを許可する」を押します。スマホを Wi-Fi で探すために必要です。
- Mac でローカルネットワークの利用の許可を求められたら、許可します。

</details>

<details markdown="1">
<summary>切断と、スマホの電池</summary>

- 「Androidとの通信」の「切断」を押すと切れます。次に Aoi を起動しても、自分で「接続」を押すまでつなぎません。
- 画面を受け取っている間、スマホは画面を長い辺 1920 ピクセルまでの動画にして毎秒 5 枚まで送ります（画面が止まっていれば毎秒 0.1〜0.2MB ほど）。そのためにスマホへ小さなプログラム（scrcpy のサーバー、約 0.7MB）を置きます。
- スマホの電池を使うので、読ませないときは、右上の状態の表示を押して一時中断するか、切断してください。一時中断の間は画面を受け取りません。
- Wi-Fi のペア設定をやめるときは、スマホの「ワイヤレス デバッグ」の画面にある「ペア設定済みのデバイス」から「Aoi」を選んで削除します。

</details>

<details markdown="1">
<summary>うまくいかないとき</summary>

| 表示や様子                          | 確かめること                                                                   |
| ----------------------------------- | ------------------------------------------------------------------------------ |
| USB でつないでも進まない            | 「USB デバッグ」がオンか。データを送れるケーブルか。スマホに許可が出ていないか |
| QR コードを読み取っても進まない     | PC とスマホが同じ Wi-Fi か。ゲスト用の Wi-Fi ではないか                        |
| 「（機種名）を探しています…」のまま | ケーブルがつながっているか、スマホの「ワイヤレス デバッグ」がオンか            |
| 「ペア設定できませんでした」        | 「もう一度」を押して、新しい QR コードを読み取り直す                           |

USB では、PC で Android Studio などの `adb` が動いていると、Aoi がスマホをつかめないことがあります。そのときは `adb` を止めてください。

</details>
