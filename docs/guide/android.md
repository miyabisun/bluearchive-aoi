# Android のスマホの画面を読む

Android 版ブルーアーカイブの画面を、Wi-Fi で PC（Windows・Mac）の Aoi に送って読ませます。
スマホにアプリを入れたり、ケーブルでつないだり、ターミナルを開いたりする必要はありません。

## 必要なもの

- Android 11 以降のスマホ（ブルーアーカイブが入っているもの）
- PC とスマホが同じ Wi-Fi につながっていること。ゲスト用の Wi-Fi など、つながった機器どうしが
  通信できない回線では使えません。

Windows の PC と Pixel 9 で確かめています。Mac での動作は、まだ確かめていません。

## 初めてつなぐ

スマホの画面の名前は Pixel のものです。機種によって少し違います。

1. スマホの「設定」→「デバイス情報」→「ビルド番号」を 7 回タップして、開発者向けオプションを
   有効にします（初回だけ）。
2. 「設定」→「システム」→「開発者向けオプション」→「ワイヤレス デバッグ」をオンにし、その項目を
   押して開きます。このネットワークでの許可を求められたら許可します。
3. Aoi の右上の「≡」から「Androidとの通信」を押すと、QR コードが出ます。
4. スマホの「QR コードによるデバイスのペア設定」を押して、Aoi の QR コードを読み取ります。
   スマホのカメラアプリで読むのではなく、この画面から読み取ってください。
5. Aoi に「（機種名）の画面を受け取っています」と出たらつながっています。
   - Windows で「Windows セキュリティの重要な警告」が出たら、「アクセスを許可する」を押します。
     スマホを Wi-Fi で探すために必要です。
   - Mac でローカルネットワークの利用の許可を求められたら、許可します。

あとはブルーアーカイブを開いて、PC と同じように [一覧や生徒の画面を送ります](reading.md)。

## 2 回目から

Aoi を起動して、スマホの「ワイヤレス デバッグ」をオンにすれば、自動でつながります。
QR コードを読み取り直す必要はありません。

## 切断する

「Androidとの通信」の「切断」を押します。次に Aoi を起動しても、自分で「接続」を押すまでつなぎません。
画面を受け取っている間は、スマホの画面を Wi-Fi で毎秒 10MB ほど（Pixel 9 で測ったとき）送るので、
スマホの電池と通信量を使います。
読ませないときは、右上の状態の表示を押して一時中断するか、切断してください。一時中断の間は画面を受け取りません。

ペア設定をやめるときは、スマホの「ワイヤレス デバッグ」の画面にある「ペア設定済みのデバイス」から
「Aoi」を選んで削除します。

## うまくいかないとき

| 表示や様子                          | 確かめること                                                |
| ----------------------------------- | ----------------------------------------------------------- |
| QR コードを読み取っても進まない     | PC とスマホが同じ Wi-Fi か。ゲスト用の Wi-Fi ではないか     |
| 「（機種名）を探しています…」のまま | スマホの「ワイヤレス デバッグ」がオンか。PC と同じ Wi-Fi か |
| 「ペア設定できませんでした」        | 「もう一度」を押して、新しい QR コードを読み取り直す        |
