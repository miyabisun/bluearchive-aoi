# Android のスマホの画面を読む

Android 版ブルーアーカイブの画面を、USB ケーブルか Wi-Fi で PC（Windows・Mac）の Aoi に送って
読ませます。スマホにアプリを入れたり、ターミナルを開いたりする必要はありません。

- USB ケーブル: つなげばすぐに使えます。Wi-Fi より安定しています。
- Wi-Fi: ケーブルが要りません。ただし、スマホの「ワイヤレス デバッグ」は Wi-Fi が切れるなどすると
  止まるので、そのつどオンに戻します。

配信アプリから送ることもできます（[配信アプリでスマホの画面を送る](stream.md)）。

## 必要なもの

- Android 11 以降のスマホやタブレット（ブルーアーカイブが入っているもの）
- USB でつなぐとき: データを送れる USB ケーブル（充電専用のケーブルでは使えません）
- Wi-Fi でつなぐとき: PC とスマホが同じ Wi-Fi につながっていること。ゲスト用の Wi-Fi など、
  つながった機器どうしが通信できない回線では使えません。

Windows の PC と Legion Tab Y700（USB）で確かめています。Wi-Fi は今の画面の受け取り方ではまだ
確かめておらず、Mac での動作も確かめていません。

## 初めてつなぐ

スマホの画面の名前は Pixel のものです。機種によって少し違います。

1. スマホの「設定」→「デバイス情報」→「ビルド番号」を 7 回タップして、開発者向けオプションを
   有効にします（初回だけ）。
2. Aoi の右上の「≡」から「Androidとの通信」を押します。
3. USB か Wi-Fi のどちらかでつなぎます。
   - USB: スマホの「設定」→「システム」→「開発者向けオプション」→「USB デバッグ」をオンにして、
     ケーブルで PC につなぎます。スマホに「USB デバッグを許可しますか？」と出たら、
     「このパソコンからの USB デバッグを常に許可する」にチェックを入れて「許可」を押します。
   - Wi-Fi: 「開発者向けオプション」→「ワイヤレス デバッグ」をオンにし、その項目を押して開きます。
     「QR コードによるデバイスのペア設定」を押して、Aoi に出た QR コードを読み取ります。
     スマホのカメラアプリで読むのではなく、この画面から読み取ってください。
4. Aoi に「（機種名）の画面を USB で受け取っています」（Wi-Fi なら「Wi-Fi で」）と出たら
   つながっています。
   - Windows で「Windows セキュリティの重要な警告」が出たら、「アクセスを許可する」を押します。
     スマホを Wi-Fi で探すために必要です。
   - Mac でローカルネットワークの利用の許可を求められたら、許可します。

あとはブルーアーカイブを開いて、PC と同じように [一覧や生徒の画面を送ります](reading.md)。

## 2 回目から

Aoi を起動して、USB ケーブルでつなぐか、スマホの「ワイヤレス デバッグ」をオンにすれば、自動で
つながります。両方つながるときは USB を使います。QR コードを読み取り直す必要はありません。
Wi-Fi で使うには、一度 QR コードでペア設定しておく必要があります。

## 切断する

「Androidとの通信」の「切断」を押します。次に Aoi を起動しても、自分で「接続」を押すまでつなぎません。
画面を受け取っている間、スマホは画面を長い辺 1920 ピクセルまでの動画にして毎秒 5 枚まで送ります（画面が止まっていれば毎秒 0.1〜0.2MB
ほど）。そのためにスマホへ小さなプログラム（scrcpy のサーバー、約 0.7MB）を置きます。スマホの電池を使うので、読ませないときは、右上の状態の表示を押して一時中断するか、切断してください。
一時中断の間は画面を受け取りません。

Wi-Fi のペア設定をやめるときは、スマホの「ワイヤレス デバッグ」の画面にある「ペア設定済みのデバイス」
から「Aoi」を選んで削除します。

## うまくいかないとき

| 表示や様子                          | 確かめること                                                                   |
| ----------------------------------- | ------------------------------------------------------------------------------ |
| USB でつないでも進まない            | 「USB デバッグ」がオンか。データを送れるケーブルか。スマホに許可が出ていないか |
| QR コードを読み取っても進まない     | PC とスマホが同じ Wi-Fi か。ゲスト用の Wi-Fi ではないか                        |
| 「（機種名）を探しています…」のまま | ケーブルがつながっているか、スマホの「ワイヤレス デバッグ」がオンか            |
| 「ペア設定できませんでした」        | 「もう一度」を押して、新しい QR コードを読み取り直す                           |

USB では、PC で Android Studio などの `adb` が動いていると、Aoi がスマホをつかめないことがあります。
そのときは `adb` を止めてください。
